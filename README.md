# drajoyceradis.com

Site da Dra. Joyce Radis, servido pelo GitHub Pages da organização no domínio `drajoyceradis.com` (arquivo `CNAME`).

- `/outubro-rosa/`: ficha de pré-avaliação do Outubro Rosa. O PDF é gerado no aparelho da paciente e só chega à médica se ela enviar pelo WhatsApp. Contato, chave Pix e endereço público ficam no objeto `CONFIG` no topo de `outubro-rosa/app.js`.
- A página inicial redireciona para `/outubro-rosa/` enquanto o site principal não está no ar.
